# Maintenance Schedule

## Daily

- Confirm containers are healthy.
- Check disk usage and upload growth.
- Review critical API and bot errors.
- Confirm backups completed.

## Weekly

- Review Dependabot pull requests.
- Review failed CI and security scans.
- Verify recent backup files are readable.
- Check certificate expiration and reverse proxy logs.

## Monthly

- Restore a backup in staging.
- Review administrator access.
- Patch operating system and container images.
- Review capacity trends and slow database queries.
- Confirm incident contacts and deployment documentation remain current.
